# front-end-back-end-practice2

# Практические работы по фронтенду и бэкенду

## Список практик

[ОСНОВНОЙ САЙТИК](https://kartohkaa.github.io/front-end-back-end-practice2/)

### [Практика 1: CSS-препроцессоры (SASS)](Practice1/)
Карточка товара с использованием переменных, миксинов и вложенности селекторов.

### [Практика 2: Сервер на Node.js + Express](Practice2/)
API и CRUD.

### [Практика 3: Тестирование API в Postman](Practice3/)
Тестирование созданного и выбранного (погода) API с помощью Postman. 

### [Практика 4: API + React ](Practice4/)
Создание полноценного веб-приложения: бэкенд на Express (CRUD для товаров) и фронтенд на React. Реализация интернет-магазина с возможностью просмотра, добавления, редактирования и удаления товаров через API. Стилизация с использованием SCSS.

### [Практика 5: Авто-документация через Swagger](Practice5/)
Доработка бэкенд части веб-приложения: подключение Swagger для авто-генерации документации API. Все CRUD операции и интерфейс на http://localhost:3000/api-docs.

### [Практика 7: Базовые методы аутентификации](Practice7/)
Реализация серверного приложения на Node.js с регистрацией и входом пользователей. Хеширование паролей с использованием bcrypt. Создание маршрутов для управления товарами с разделением прав доступа.

### [Практика 8: JWT авторизация](Practice8-10/)
Доработка серверного приложения из практики 5 - добавление JWT-токенов для авторизации. Реализация защищенных маршрутов для работы с товарами (создание, редактирование, удаление доступны только авторизованным пользователям). Фронтенд: окна входа и регистрации.

### [Практика 9: Referesh токены](Practice8-11/)
Доработка серверной части: refresh-токены для обновления access-токенов без повторной аутентификации. Реализация хранения refresh-токенов на сервере


### [Практика 10: Управление токенами и доработка сайта](Practice8-11/)
Связанные системы авторизации с фронтендом: хранение access-токена в localStorage, автоматическая подстановка токена в заголовки запросов, обработка ошибок 401 и автоматическое обновление токенов через refresh-механизм.

### [Практика 11: RBAC](Practice8-11/)
Система (гость, пользователь, продавец, администратор). Разграничение прав доступа к маршрутам: просмотр товаров доступен всем, создание и редактирование - продавцам и администраторам, удаление товаров и управление пользователями - только администратору. Добавлена админ-панель для управления пользователями.


### [Практика 13: Service Worker](Practice13-14/)
Реализация офлайн-доступа для веб-приложения заметок. Использование Service Worker для кэширования статических ресурсов (HTML, CSS, JS, манифест, иконки). Перехват сетевых запросов и отдача данных из кэша при отсутствии интернета. Локальное хранение заметок в localStorage. Индикатор состояния сети. Приложение полностью работоспособно без подключения к интернету.

### [Практика 14: Web App Manifest (PWA)](Practice13-14/)
Превращаем приложение в прогрессивное веб-приложение (PWA). Создание файла manifest.json с настройками: имя, короткое имя, тема, фоновый цвет, ориентация, иконки. Подготовка набора иконок разных размеров (16x16 до 512x512). Добавление мета-тегов для iOS и Android. Обновление Service Worker для кэширования иконок. Возможность установки приложения на устройство и запуск в отдельном окне без элементов браузера.

### [Практика 15: HTTPS + App Shell](Practice15-16/)
Настройка локального HTTPS с использованием mkcert для корректной работы Service Worker и PWA. Реализация архитектуры App Shell: кэширование статического каркаса приложения (шапка, меню, подвал) при первом посещении и динамическая подгрузка контента. Добавлена страница "О студенте" и "О приложении". Приложение работает офлайн и загружается мгновенно.

### [Практика 16: WebSocket + Push уведомления](Practice15-16/)
Интеграция WebSocket (Socket.IO) для двусторонней связи между клиентами в реальном времени. Реализация push-уведомлений через Service Worker с использованием VAPID-ключей. При добавлении заметки все подключенные клиенты получают уведомление через WebSocket, а также системное push-уведомление (даже при закрытом приложении). Добавлены кнопки включения/отключения уведомлений.
